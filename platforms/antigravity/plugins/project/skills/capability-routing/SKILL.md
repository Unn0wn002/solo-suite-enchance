# Capability Routing

Read `capability-inventory.json`, `CAPABILITY_ROADMAP.md`, and relevant `.solo/`
memory before selecting skills. Identify the phase, one owner, supporting
plugins, required inputs, output artifact, next handoff, and evidence gate.

Use Graphify for architecture, bounded native search for symbols, primary
official sources through reviewed host web access for current documentation,
and Repomix for bounded snapshots. Aider, Serena, Context7, and Code Review
Graph are rejected audit sources with no activation path. Preserve upstream
attribution and check licenses.

Write `.solo/capability-plan.md`:

```markdown
# Capability Plan — <request>
## Phase and owner
## Activated plugins
## Activated skills / commands
## Inputs
## Outputs and handoffs
## Acceptance and evidence gates
## Excluded capabilities
## Risks, licensing, and security notes
## Next skill
```

End with: **Owner · Inputs · Work · Output · Evidence · Next command**.
