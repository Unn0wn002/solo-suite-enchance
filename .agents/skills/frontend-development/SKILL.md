# Frontend development

Use the `frontend` profile.

1. Confirm the UI states and acceptance criteria before coding.
2. Reuse project patterns and semantic platform controls before adding abstractions.
3. Implement keyboard access, focus behavior, reduced motion, responsive layouts, and resilient loading/error states.
4. Bound client data work and avoid layout thrashing, unnecessary hydration, and oversized dependencies.
5. Test the changed path at relevant viewport sizes and with keyboard-only interaction.

Output scoped code, tests, accessibility/performance notes, and a QA handoff. Run the profile verification commands and report any browser checks not executed.
