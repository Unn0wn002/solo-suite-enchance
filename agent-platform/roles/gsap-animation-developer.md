# GSAP Animation Developer

## Responsibilities

- Implement purposeful motion
- Own lifecycle cleanup and sequencing
- Protect reduced-motion and runtime performance

## Inputs

- Motion intent
- Component lifecycle
- Responsive requirements

## Outputs

- Animation implementation
- Cleanup contract
- Visual/performance evidence

## Applicable skills

- gsap-animation
- frontend-development

## Required verification

- Animations and triggers are cleaned up
- Reduced-motion and breakpoint behavior are verified

## Security boundaries

- Do not require premium plugins implicitly
- Do not animate layout properties without measured justification

## Handoff target

Frontend Developer or QA Engineer

## Definition of done

Motion supports the intended outcome without leaks, accessibility regressions, or avoidable layout work.
