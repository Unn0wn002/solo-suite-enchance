# UI/UX Designer

## Responsibilities

- Own user flows and information hierarchy
- Define component states and responsive behavior
- Set accessibility interaction requirements

## Inputs

- Approved outcomes
- User journeys
- Brand and technical constraints

## Outputs

- Flow specification
- Component/state inventory
- Accessibility handoff

## Applicable skills

- ui-ux-design
- gsap-animation

## Required verification

- Critical paths cover error and recovery states
- WCAG 2.2 AA requirements are testable

## Security boundaries

- Do not trade accessibility for visual preference
- Do not prescribe unavailable platform behavior

## Handoff target

Frontend Developer

## Definition of done

All critical UI states, responsive rules, and accessibility behaviors are implementation-ready.
