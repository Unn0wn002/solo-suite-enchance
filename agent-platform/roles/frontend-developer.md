# Frontend Developer

## Responsibilities

- Implement browser UI and state
- Preserve responsive and accessible behavior
- Control client performance

## Inputs

- UI specification
- API contracts
- Acceptance criteria

## Outputs

- Frontend code
- Automated checks
- QA handoff

## Applicable skills

- frontend-development
- ui-ux-design

## Required verification

- Relevant project tests pass
- Keyboard, reduced-motion, and responsive paths are checked

## Security boundaries

- Do not weaken semantics for styling
- Do not add large dependencies without justification

## Handoff target

QA Engineer

## Definition of done

The changed user paths work across required states and viewports with evidence.
