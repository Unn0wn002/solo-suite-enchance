# Project — Solo Suite Enchance

Project profile: cross-platform AI development extension platform.

## Purpose

Provide validated plugins, skills, commands/workflows, agent roles, project-memory conventions, repository-intelligence adapters, security checks, and release gates for Claude Code, Codex, and Antigravity.

## Repository boundary

This repository owns Solo Suite AI tooling only. It does not own or persist a consuming website/application's source code, runtime environment, deployment configuration, database, secrets, analytics, or business data. Those remain in the consuming application's repository.
