# Release — Solo Suite Enchance

Release scope is the AI extension/distribution repository only.

A release should identify the source commit, validate generated mirrors and cross-platform parity, run repository security/remediation gates, run Claude/Codex/Antigravity native validation, and document any manual/platform-specific checks not executed.

There is no website/application deployment step in the Solo Suite release path. Consuming projects deploy through their own repository and infrastructure.
